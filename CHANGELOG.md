## Unreleased

- Home screen, "Chi phí": Codex spend now shows up. The box reads every Codex home (`~/.codex`, `~/.codex-*`, `~/.codex-accounts/*`, each real folder once), not only one, so the Astra runs of every account are counted. The gpt-6 models (astra, sol, luna, terra, 6.1, cyber, rosalind, astra-law) now have prices, cache writes are priced, and a request above 272,000 input tokens is billed at the higher long-context rate (2x input and cache, 1.5x output) for the models whose OpenAI page states it.
- Box guard for workflow changes in repos with secrets: any file under `.github/` on the default branch contains the word `secrets` (any case), or the repo is listed in `~/.config/fcode/sensitive-repos`; an unresolvable or unreadable default branch counts as one. The box pre-push hook (`box/fcode-add.sh` `hook_text`, still blocking main/master) now refuses, in such a repo (the pushed tree counts too), every pushed branch or tag whose tree under `.github/` differs from the remote ref's current value (a new ref: the default branch). New `box/gh-guard.sh`, installed as `~/.local/bin/gh` ahead of `/usr/bin/gh`, refuses (exit 65): a first word that is not a built-in gh command (aliases, extensions); `gh pr merge` / `gh api` calls with unknown flags (parsed like pflag; `--help` changes nothing); there, `gh pr merge` with any auto flag, or of a PR whose REST file list (new and old names) touches `.github/` or is incomplete; every `gh api graphql`; any non-GET `gh api` call whose target is not plainly `repos/<o>/<r>` or is such a repo. Allowed merges there run pinned to the inspected head (`--match-head-commit`). A one-shot owner-approved allow file `~/.config/fcode/guard-allow/<owner>__<repo>__<sha>` (mode 600, created by the Architect after the owner's Yes) lets that exact commit be pushed and merged; each use is logged to `~/.local/state/fcode/guard-allow.log` and the file is removed after the merge. The rule text is shared verbatim by the hook and the guard. New `box/fcode-hooks.sh` (`~/.local/bin/fcode-hooks`, run by `install.sh`) puts the current hook into every project already added (a relative `core.hooksPath` is read from the project); `fcode-add.sh --hook-text` prints it. Not a security boundary (the VPS forced-command deploy keys are); see docs/HUONG-DAN.md, "Sửa workflow từ box".
