# Changelog

## Unreleased

- Home screen, "Chi phí": Codex spend now shows up. The box reads every Codex home (`~/.codex`, `~/.codex-*`, `~/.codex-accounts/*`, each real folder once), not only one, so the Astra runs of every account are counted. The gpt-6 models (astra, sol, luna, terra, 6.1, cyber, rosalind, astra-law) now have prices, cache writes are priced, and a request above 272,000 input tokens is billed at the higher long-context rate (2x input and cache, 1.5x output) for the models whose OpenAI page states it.
- Box guard for workflow changes in repos with secrets (a workflow on the default branch reads `secrets.<NAME>` other than `GITHUB_TOKEN`, or the repo is listed in `~/.config/fcode/sensitive-repos`; an unreadable default branch counts as one). The box pre-push hook (`box/fcode-add.sh` `hook_text`, still blocking main/master) now refuses a push whose new commits change `.github/` in such a repo. New `box/gh-guard.sh`, installed as `~/.local/bin/gh` ahead of `/usr/bin/gh`: refuses (exit 65) `gh pr merge` of a PR that changes `.github/` there, and `gh api` PUT/PATCH/DELETE on its `contents/.github`, `actions/secrets` or `environments`; every other call goes to `/usr/bin/gh` unchanged. New `box/fcode-hooks.sh` (`~/.local/bin/fcode-hooks`, run by `install.sh`) puts the current hook into every project already added; `fcode-add.sh --hook-text` prints it. Client-side defence in depth only; see docs/HUONG-DAN.md, "Sửa workflow từ box".
